# Printable enclosure parts

Print one each: [base](base.stl), [faceplate](faceplate.stl), [LED retainer](led-retainer.stl), [Feather retainer](feather-retainer.stl). All four are oriented for the print bed, in millimetres.

Regenerated from the saved native CAD at handoff `294cd1f`. Each mesh is watertight, consistently wound, one connected solid, and fits a 180 × 180 mm bed. See [mesh checks](../../validation/print-meshes.json).

PETG starting settings: 0.4 mm nozzle, 0.20 mm layers, four perimeters, supports off. Use a tested material profile and inspect your slicer preview. Physical fit and thermal testing remain pending. Follow the [build guide](../../../docs/Halloween-LEDs-Build-Guide.pdf) for assembly.
