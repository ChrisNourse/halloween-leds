# v0.9.2 — experimental patch update

This update follows v0.9.0 and improves contribution and release checks:

- Require pull requests for all updates to `main`, including administrator changes.
- Run host tests, Chromium browser tests and workflow linting on PRs and after merges, with all three checks required for merging.
- Save reports and traces for failed browser checks.
- Resolve source links in generated release notes to the corresponding version tag.
- Read the build-guide version from `package.json` so its cover, metadata and page footers stay consistent when regenerated.

The hardware design is unchanged. Hardware qualification remains in progress as described in the status below. Version v0.9.1 was not published; v0.9.2 includes both follow-up change batches since the initial release.
