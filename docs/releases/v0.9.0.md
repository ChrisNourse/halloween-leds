# v0.9.0 — first experimental release

A battery-powered, sixteen-pixel Halloween uplight with browser controls and an editable printed enclosure.

- Standalone CircuitPython lighting with six patterns, editable gradients, saved settings and sunset/sunrise scheduling.
- Wi-Fi browser controls, optional USB controls, USB installation and verified OTA application updates.
- Four printable enclosure parts, native editable CAD, parts list, wiring documentation and an illustrated build guide.
- Reciprocal licenses for software, hardware and original documentation.

Download the PDF for assembly instructions. The project ZIP includes firmware, website, native CAD, STLs, documentation and license texts. Hardware qualification is in progress; the status below describes the limitations of this release.
