Connection & OTA updates

Open http://halloween.local on the same Wi-Fi network to control the lights directly. For USB control from this Mac, use Chrome or Edge and select the Feather’s data interface, usually the second port. Debugging uses the first port or the Wi-Fi console.

With the sunset schedule enabled, the board sleeps during the day and wakes automatically for sunset. The website, OTA service, and heartbeat are off during deep sleep. Press BOOT to wake it for access. Turning off the sunset schedule keeps manual controls and Wi-Fi available.

Connect to read the board’s OTA address.

Firmware and OTA updates are managed from this repository. Run uv run scripts/device.py ota --url http://halloween.local:8080 while the board is awake. The USB disk stays hidden during normal use so OTA can write safely. OTA updates application files and this website; install CircuitPython runtime updates over USB.

If attaching the sticks stops the board from running, unplug power and check 5V, ground, DIN and DOUT wiring before reconnecting.
